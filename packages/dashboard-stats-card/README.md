# @kaijudo/dashboard-stats-card

A React component package.

## Installation

```bash
pnpm add @kaijudo/dashboard-stats-card
```

## Usage

```tsx
import { DashboardStatsCard } from '@kaijudo/dashboard-stats-card';

function App() {
  return <DashboardStatsCard>Hello World</DashboardStatsCard>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
