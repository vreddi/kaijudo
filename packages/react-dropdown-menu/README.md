# @kaijudo/react-dropdown-menu

A React component package.

## Installation

```bash
pnpm add @kaijudo/react-dropdown-menu
```

## Usage

```tsx
import { ReactDropdownMenu } from '@kaijudo/react-dropdown-menu';

function App() {
  return <ReactDropdownMenu>Hello World</ReactDropdownMenu>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
