# @kaijudo/react-header

A React component package.

## Installation

```bash
pnpm add @kaijudo/react-header
```

## Usage

```tsx
import { ReactHeader } from '@kaijudo/react-header';

function App() {
  return <ReactHeader>Hello World</ReactHeader>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
