# @kaijudo/dashboard-creature-card

A React component package.

## Installation

```bash
pnpm add @kaijudo/dashboard-creature-card
```

## Usage

```tsx
import { DashboardCreatureCard } from '@kaijudo/dashboard-creature-card';

function App() {
  return <DashboardCreatureCard>Hello World</DashboardCreatureCard>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
