# @kaijudo/react-avatar

A React component package.

## Installation

```bash
pnpm add @kaijudo/react-avatar
```

## Usage

```tsx
import { ReactAvatar } from '@kaijudo/react-avatar';

function App() {
  return <ReactAvatar>Hello World</ReactAvatar>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
