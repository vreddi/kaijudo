# @kaijudo/react-storybook

A React component package.

## Installation

```bash
pnpm add @kaijudo/react-storybook
```

## Usage

```tsx
import { ReactStorybook } from '@kaijudo/react-storybook';

function App() {
  return <ReactStorybook>Hello World</ReactStorybook>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
