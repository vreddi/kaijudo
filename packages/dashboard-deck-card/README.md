# @kaijudo/dashboard-deck-card

A React component package.

## Installation

```bash
pnpm add @kaijudo/dashboard-deck-card
```

## Usage

```tsx
import { DashboardDeckCard } from '@kaijudo/dashboard-deck-card';

function App() {
  return <DashboardDeckCard>Hello World</DashboardDeckCard>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
