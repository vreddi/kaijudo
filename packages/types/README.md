# @kaijudo/types

A React component package.

## Installation

```bash
pnpm add @kaijudo/types
```

## Usage

```tsx
import { Types } from '@kaijudo/types';

function App() {
  return <Types>Hello World</Types>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
