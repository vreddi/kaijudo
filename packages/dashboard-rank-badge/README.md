# @kaijudo/dashboard-rank-badge

A React component package.

## Installation

```bash
pnpm add @kaijudo/dashboard-rank-badge
```

## Usage

```tsx
import { DashboardRankBadge } from '@kaijudo/dashboard-rank-badge';

function App() {
  return <DashboardRankBadge>Hello World</DashboardRankBadge>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
