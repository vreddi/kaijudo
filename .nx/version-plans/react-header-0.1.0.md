Initial public release of Header component package.

## Features

- Configurable header component with transparent background support
- Integration with `@kaijudo/react-profile-dropdown` for user profile and sign out
- Flexible layout with logo, navigation, and profile sections
- Comprehensive Storybook stories and documentation
- Full TypeScript support with proper type definitions

### Components

- `Header` - Main header component with configurable props

### Props

- `logo` - Logo or brand element (left side)
- `navigation` - Navigation items (center, optional)
- `profile` - Profile data for ProfileDropdown
- `onSignOut` - Callback function for sign out
- `showProfile` - Toggle profile dropdown visibility
- `transparent` - Transparent or solid background option
- `children` - Custom content support
