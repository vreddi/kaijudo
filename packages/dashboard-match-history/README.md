# @kaijudo/dashboard-match-history

A React component package.

## Installation

```bash
pnpm add @kaijudo/dashboard-match-history
```

## Usage

```tsx
import { DashboardMatchHistory } from '@kaijudo/dashboard-match-history';

function App() {
  return <DashboardMatchHistory>Hello World</DashboardMatchHistory>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
