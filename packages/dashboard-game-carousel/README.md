# @kaijudo/dashboard-game-carousel

A React component package.

## Installation

```bash
pnpm add @kaijudo/dashboard-game-carousel
```

## Usage

```tsx
import { DashboardGameCarousel } from '@kaijudo/dashboard-game-carousel';

function App() {
  return <DashboardGameCarousel>Hello World</DashboardGameCarousel>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
