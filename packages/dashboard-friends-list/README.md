# @kaijudo/dashboard-friends-list

A React component package.

## Installation

```bash
pnpm add @kaijudo/dashboard-friends-list
```

## Usage

```tsx
import { DashboardFriendsList } from '@kaijudo/dashboard-friends-list';

function App() {
  return <DashboardFriendsList>Hello World</DashboardFriendsList>;
}
```

## Development

### Build

```bash
pnpm build
```

### Storybook

Run Storybook to view and test the component:

```bash
pnpm storybook
```

Build static Storybook:

```bash
pnpm build-storybook
```
